Good to know

Frequently asked questions.

Is CodeShot free to use?

Yes. CodeShot is free to use for generating and downloading code screenshots.

Which programming languages are supported?

CodeShot supports Python, JavaScript, Java, TypeScript, HTML, CSS, Go, and Rust.

Can I add line numbers to my code?

Yes. You can enable line numbers in the editor settings to make code snippets easier to reference and discuss.

Do you support dark and light themes?

Absolutely. Choose from a range of dark and light themes to match the style of your project or presentation.

What file format do I get when I download?

The generated image exports as a high-resolution PNG, ready to share in docs, blog posts, tickets, and social media.

Is my code kept private?

CodeShot processes the snippet locally in the browser and does not store your pasted code in the generated image itself.

Can I use the generated image commercially?

Yes. Once you download the PNG, you can use it in presentations, documentation, and other shareable content.

How do I make a snippet easier to read?

Use a clear theme, enable line numbers, adjust the editor width, and keep the code focused on the specific part you want to highlight.

Can I switch the language after pasting code?

Yes. You can change the language selector at any time to match your snippet and improve the highlighted output.

Do I need to use the window frame in the preview?

No. The window controls toggle is optional, so you can keep the image minimal or add the desktop-style frame for a more polished look.

What is the difference between Generate image and Export PNG?

Generate image previews the result in the app, while Export PNG downloads the final high-resolution screenshot for sharing.

Can I create screenshots for documentation or blog posts?

Yes. CodeShot is designed for code snippets that need to be shared in tutorials, documentation, issue threads, and technical posts.

Does CodeShot support lots of languages?

Yes. CodeShot includes a wide range of languages including Python, JavaScript, TypeScript, Go, Rust, SQL, JSON, YAML, and many more.
