# CodeShot

CodeShot is a web-based tool that turns code snippets into clean, polished PNG images for sharing in documentation, presentations, social media, and developer portfolios.

## Features

- Generate images from code snippets
- Syntax highlighting
- Multiple programming languages
- Multiple code themes
- Optional line numbers
- Optional macOS-style window controls
- High-resolution PNG export
- Live character counter
- Clean and responsive interface

## How It Works

1. Enter or paste your code.
2. Select the programming language.
3. Choose a visual theme.
4. Customize line numbers and window controls.
5. Generate the code image.
6. Export it as a PNG.
